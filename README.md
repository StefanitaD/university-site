# University Site

A small static website for playlists and song pages used for an university project.

Project structure:

- `index.html` — main landing page.
- `content/` — playlist/songs pages.

Usage
-----

Open `index.html` in your web browser to view the site locally. No build steps or server are required for basic usage.

If you want to serve the site locally with a simple HTTP server (optional):

For Python 3:

```
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

Contributing
------------

Edit the HTML files under the project root or the `content/` folder and refresh the browser to see changes.
